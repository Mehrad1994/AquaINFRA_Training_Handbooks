# The Gulf of Riga Data-to-Knowledge Package

<p class="chapter-meta">Chapter 4 of 9</p>

<div class="chapter-intro">
    <p>A <a href="{{ relative_root }}reference/glossary#d2kp">Data-to-Knowledge Package</a> bundles everything needed to reproduce one analysis - the data, the Galaxy workflow, the code, a virtual lab, and the docs - behind a single citable DOI. This chapter tours the Gulf of Riga package and its entry points: run it, edit it, integrate it, or archive it. <a href="https://aquainfra.dev.52north.org/result/zenodo:17175368" target="_blank" rel="noopener">Open the live D2KP</a>.</p>
