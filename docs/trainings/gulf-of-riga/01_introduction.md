# Introduction to AquaINFRA

<p class="chapter-meta">Chapter 1 of 9</p>

<div class="chapter-intro">
    <p>AquaINFRA is a virtual research environment that lets marine and freshwater scientists find data, run analyses, and share reproducible workflows - all <a href="{{ relative_root }}reference/glossary#fair">FAIR</a> and plugged into the <a href="{{ relative_root }}reference/glossary#eosc">European Open Science Cloud</a>. This opening chapter sets the scene for the Gulf of Riga case study, which runs the full AIP → D2KP → VRE chain to answer one real question about water transparency.</p>
