## Key points

- **Find it:** on the AIP, search *"Data to Knowledge Package"* → select *"…for Specleaner: A toolkit for ensemble outlier detection and removal."* 🔗 <a href="https://aquainfra.dev.52north.org/result/zenodo:17175591" target="_blank" rel="noopener">Live D2KP</a>.
- **Five sections, pick by what you want to do:**

<div class="table-wrapper">
    <table>
        <thead><tr><th>Section</th><th>Gives you</th><th>Best for</th></tr></thead>
        <tbody>
            <tr><td><strong>VRE (workflow)</strong></td><td>The Galaxy workflow (or Zenodo backup).</td><td><em>Running</em> the analysis.</td></tr>
            <tr><td><strong>Virtual Lab (Binder)</strong></td><td>RStudio with the code pre-loaded.</td><td><em>Editing</em> the algorithm.</td></tr>
            <tr><td><strong>Web API (pygeoapi)</strong></td><td>OGC endpoints (BOKU's processes under <code>"Boku"</code>).</td><td><em>Integrating</em> into other systems.</td></tr>
            <tr><td><strong>Reproducible basis</strong></td><td>Full toolbox on GitHub + Zenodo, with DOIs.</td><td>Reviewers, archivists.</td></tr>
            <tr><td><strong>Datasets</strong></td><td>Direct download links (e.g. the GeoJSON area of interest).</td><td>Getting the demo inputs.</td></tr>
        </tbody>
    </table>
</div>

> [!TIP]
> Not sure? **Start with the VRE (workflow)** and drop down to the other sections only when you need more control.

---

## ✅ Key takeaways

- The D2KP is structured by **interaction level** - run, edit, integrate, or archive.
- Everything is **permanently archived** on Zenodo/GitHub and citable by **DOI**.
